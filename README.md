NOTEPAD APPLICATION

A clean, distraction-free desktop note-taking application with instant search, local device storage, and live word count tracking.

Features

Two-Pane Interface: Browse and switch between saved notes on the left sidebar while reading or composing in the main editor pane on the right.

Instant Search: Filter your notes in real time using the search bar at the top of the sidebar.

Full Note Management: Create new notes (New note), modify existing ones (Edit), or remove unwanted entries (Delete note).

Automatic Timestamps: Tracks and displays the last edited date and time beneath each note title.

Live Word Counter: Displays the current word count at the bottom of the editor pane.

Offline Local Storage: All notes are saved directly on your device (Notes saved on this device) in plain text format.
